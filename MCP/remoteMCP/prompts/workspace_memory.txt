This is the StreamingAssets folder for a Unity-based nursing training simulation project.  The Scenario folder contains scenario script files written in the Cerebrum language.  The Cerebrum language is a loosely typed language described in the document Docs/CerebrumProgrammingGuide.doc.  It is designed to be a modular language so new capabilities can be added without rebuilding the Unity project.  Cerebrum controls the logic of the simulation scenario, and commands in the language can be extended by adding new files which act as functions, such as GivePatientCup.txt adding a new functionality to hand the patient a cup.  Variable names begin with a $ which can be omitted in places where a variable is expected.  Each file name together with the file path is the name of the function that can be called with the Cerebrum language’s Do command (such as the command Do ‘Action/GivePatientCup’ , and the directory structure groups commands by purpose.   Most commands are in a noun-verb-modifier format which corresponds to the Unity game object, the action that object is performing, and optional parameters that action is acting on.  Unity game objects can have MessageHandlers written in C# which allow GameObjects to understand Cerebrum actions, such as the nurse knowing the actions grabLeft and grabRight in the following Cerebrum code:
$PlayerNurse = 'Player/NursePlayer’      #Unity object name
$Grab = 'grab' + ActiveHand		#action is either grabLeft or grabRight
$PlayerNurse $Grab $Item 1 'grip' 'default'    #have nurse grab the item with chosen hand and default grip type
Originally the language supported branching with a Goto command which would branch to a line number or Label, but now the language supports the preferred While-Do-Endwhile or WaitFor loops.  Commands must appear on separate file lines, and conditional statements must appear on their own line following If or While statements rather than in parentheses like many other languages.  Also, spaces are used to separate parameters rather than commas.
