Put corrected LevelGen files in this folder after you manually test/fix them in Unity.
The server treats files in this folder as the most important examples when generating new LevelGen files.

Workflow:
1. Manually create a LevelGen file.
2. Test it in Unity.
3. Fix object names/columns until it works.
4. Copy the final working file into this folder.
5. Refresh the web UI file index.
6. Generate new LevelGen files based on these corrected examples.
